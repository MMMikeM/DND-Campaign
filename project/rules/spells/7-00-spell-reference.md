## 7. Spell Reference

One entry per Spell, alphabetical. Each entry opens with the **Basic Effect** you can use at will for 0 SP, then its **Modes**, then the **Enhancements** available to it. Enhancements listed under a Mode apply only to that Mode. Enhancements under **General Enhancements** apply to any Mode of that spell.

You can only use Modes and Enhancements you have learned. See Section 6.4 for how you learn them, what a single cast can cost, and how costs combine.
